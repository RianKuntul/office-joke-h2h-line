One short line about office life: the printer jams on the deadline, and
the only part of it that works perfectly is the scanner used to photograph
the error for IT.

## Run

```sh
node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters, no trailing newline.
